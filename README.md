# Medical System

## Description
A system designed to streamline medical record management for healthcare providers. It enables the storage, retrieval, and updating of patient records securely.

## Features
- Patient registration and profile management.
- Appointment scheduling.
- Medical history tracking.
- Secure access for doctors and administrators.

## Technologies Used
- **Frontend:** Angular, HTML, CSS, Bootstrap
- **Backend:** C# (.NET Framework)
- **Database:** SQL Server
